# Instagram Login UI Demo

A static, educational recreation of a dark Instagram-style login screen based on a reference screenshot.

## Files
- `index.html` — page structure
- `style.css` — responsive styling

## Run locally
Open `index.html` in a browser.

## Safety note
This is a visual mockup only. The buttons do not authenticate users, the form has no submission handler, and credentials are not collected, stored, or transmitted.
